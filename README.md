# brett — lokale boards

Boards zum sammeln, organisieren, verschieben, verknüpfen von ideen, inspirationen und notizen. Lokal gespeichert ohne Limitierung. Quasi miro nur konfiguriert auf mich + lokal. Ein neues projektbasiertes aber crosslinked GUI meiner files. 

Geplante Features, Erklärung Funktionalität:
	Die Boards sind flexibel per [[drag’n’drop]] zu gestalten und flüssig durch verschieben, ordnen und  zu bearbeiten. Man kann einfach alle projektbezogenen Files direkt per drag’n’drop oder copy-paste einfügen und sie miteinander verlinken. Beim hovern über der Verlinkung wird eine Vorschau (visualisiert als Portal [[portal links]]) für das verlinkte Board angezeigt. 

Use cases:
	— Moodboards erstellen
	— Farben / [[schriften]] / Layouts testen und kombinieren
	— Abladen von Informationen zum verschieben und veranschaulichen
	— Vergleichen von Boards und Strukturen
	— Präsentieren ohne Folienerstellung
	— (Zusammenarbeiten)
